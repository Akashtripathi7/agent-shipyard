## Recap

- **An agent is a model in a loop with tools.** The model decides; the harness observes, acts and checks. Most failures are one of those steps going wrong, and the loop log tells you which.
- **Scripts for the deterministic, agents for judgment.** One check script is the source of truth.
- **AGENTS.md holds only what the code can't tell the agent,** and it's read on every turn.
- **Tools cost context and carry risk.** Pick few, prefer lean output, read before connecting.
- **Context rots before it fills.** One task per session, state in files, noisy work to subagents.
- **Done means evidence.** Test-first, and a Stop hook that won't let the agent finish while checks fail.
- **Guardrails don't depend on the model being right.** Deny rules, the sandbox, and breaking the lethal trifecta.
- **Brief outcomes and reasons, not actions.** And when the agent is wrong, make it fix its own mistake.
- **Skills hold procedures you need sometimes;** the description decides whether they trigger.
- **Size the model and effort to the job.**
